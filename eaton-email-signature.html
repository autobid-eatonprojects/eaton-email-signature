To use in Outlook: click Copy signature, then in Outlook on the web go to Settings → Account → Signatures → Add signature, click in the editor box and paste (Cmd+V / Ctrl+V). The signature appears with the logo and layout, not as code. Set it as the default for new messages and replies if you want. Only name, title, phone, mobile and email change per person; everything else is fixed.
